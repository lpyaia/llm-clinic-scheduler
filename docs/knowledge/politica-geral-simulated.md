# Políticas gerais da Clínica Horizonte simulada

Documento fictício para demonstração, sem validade para uma clínica real.

Para solicitar cópia de comprovantes administrativos, apresente identificação na recepção.
Documentos de outra pessoa exigem conferência de representação pela equipe administrativa.

Pedidos de cancelamento ou remarcação passam por identificação do atendimento, resumo e confirmação.
A publicação desta política não cancela, cria nem altera reservas.
